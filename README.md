# ado-pipelines
Azure DevOps pipelines

## GitHub MCP Server no VS Code

Este repositório configura o servidor MCP remoto oficial do GitHub em
`.vscode/mcp.json`. Para usá-lo, abra o projeto no VS Code, entre na sua conta
GitHub, inicie o Copilot Chat no modo Agent e autorize a conexão quando
solicitado. Não é necessário salvar um token no repositório.
